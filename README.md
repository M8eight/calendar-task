# Задача про календарь

## Вопрос
Сколько всего уникальных календарей существует вне зависимости от номера года?

### Ответ

Всего существует **14 уникальных вариантов календаря** независимо от номера года.

Варианты:

1. **Тип года** — год может быть:

    * обычным;
    * високосным.

2. **День недели, на который приходится 1 января** — он может быть любым из 7 дней недели.

Таким образом, количество уникальных вариантов:

``2 × 7 = 14``

## Описание программы
Пользователь указывает номер года, программа должна получать соответствующий календарь и возвращать(выводить)
содержимое.

## Данные на вход
Номер года.

## Данные на выход
Отображение содержимого календаря соответствующего введенному номера года.

## Требования
Реализовать на JAVA с соблюдением принципов ООП используя любой набор известных технологий
